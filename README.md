Репозиторий курса Евгения Борисова. Шаг за шагом собираем собственного coding-агента на Java и Spring AI: от первого запроса к модели до инструментов, памяти и самостоятельного выполнения задач.

**Попали сюда случайно и хотите пройти курс?** Заходите в [Telegram-канал Евгения Борисова](https://t.me/borisovtrainings) — там программа, подробности и информация о покупке курса.

## Для участников курса

Сейчас опубликован код до **шестого урока включительно**. Каждую неделю будет появляться следующий урок, пока курс не выйдет целиком.

Состояния проекта по урокам отмечены тегами: `lesson-NN-start` — начало урока, `lesson-NN-end` — результат. Например, код после шестого урока:

```bash
git clone https://github.com/Jeka1978/harness-course.git
cd harness-course
git checkout lesson-06-end
```

Все доступные этапы — в [списке тегов](https://github.com/Jeka1978/harness-course/tags).
